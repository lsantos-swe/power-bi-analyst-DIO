## Projetos

### 01. Análise de Vendas com Power BI

Projeto desenvolvido a partir de uma base de dados de vendas, com análises de produtos, segmentos, países, vendas, lucro e unidades vendidas.

O projeto marcou meu primeiro contato prático com o Power BI e envolveu desde a familiarização com a ferramenta até a construção e organização de um relatório completo.

[Visualizar projeto](./projeto-01-analise-de-vendas/)

### 02. Relatório Gerencial de Vendas com Power BI

Projeto voltado à construção de um relatório gerencial mais interativo, utilizando segmentadores, indicadores, ações e recursos de navegação.

O desenvolvimento permitiu avançar no uso do Power BI, com maior foco na experiência de interação com o dashboard, alternância entre visualizações e organização das informações em diferentes páginas.

[Visualizar projeto](./projeto-02-relatorio-gerencial-interativo/)
